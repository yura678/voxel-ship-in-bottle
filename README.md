# ⛵ Воксельний Корабель у Скляній Пляшці

Деталізована високопродуктивна інтерактивна 3D WebGL-діорама **«Корабель у скляній пляшці»** у стилі воксель-арт, розроблена на **Three.js**.

Усі елементи сцени — динамічний воксельний океан із фізикою хвиль, підводний кораловий риф, флагманський трищогловий корабель, скелястий острів із маяком, тропічний атол зі скринею скарбів, кам'яна морська арка, глибинний Кракен, грозові хмари та зграя чайок — **повністю інкапсульовані всередині скляної пляшки**, розташованої на дерев'яній підставці з латунною табличкою «Корабель».

---

## 🚀 Запуск проєкту

```bash
npm install
npm run dev
npm run build
```

Сервер розробки запуститься за адресою: `http://localhost:5173/`

## 🎮 Керування та Інтерактивність

- **Миша (OrbitControls):** вільне обертання камери навколо пляшки, масштабування (колесо миші) та панорамування.
- **Маневрування кораблем:** клавіші `W` / `A` / `S` / `D` або стрілки клавіатури (керування курсом у безпечному фарватері пляшки).
- **🔥 Залп гармат:** клавіша `Space` або кнопка внизу (бортовий залп 4 гармат із балістикою ядер, ударними колами та воксельними сплесками).
- **🌊 Збурити хвилю:** кнопка внизу або клік по водній поверхні (створення динамічної кругової хвилі з піною).
- **🌅 Змінити погоду:** кнопка внизу або клік по хмарах (циклічна зміна пресетів: Карибський день, Багряний захід, Біолюмінесцентна ніч, Морський шторм).
- **🚨 Маяк:** кнопка внизу або клік по маяку (перемикання прожектора маяка та звуковий сигнал туманного горна).
- **💰 Скарби острова:** кнопка внизу або клік по атолу зі скринею (фонтан золотих воксельних монет).
- **🍾 Корок пляшки:** кнопка внизу або клік по корку (фізичне відкорковування/закорковування пляшки).
- **🎥 Ракурс:** кнопка перемикання 4 кінематографічних камер (Загальний огляд, Макро-корабель, Острів скарбів, Підводний риф).
- **📊 Графік FPS:** увімкнення/приховування лічильника кадрів у реальному часі та моніторингу викликів рендеру (`Draw Calls \ ms`).
- **🐙 Кракен:** клік по Кракену під водою викликає ривок на поверхню та удар щупальцями по воді.
- **Панель налаштувань (`lil-gui`):** регулювання погоди, висоти та швидкості хвиль океану.

## 🏛️ Багатошарова Архітектура (`src/`)

Проєкт побудовано за принципами **Clean Architecture** та **SOLID**:

```text
src/
├── config/
│   └── sceneConfig.js           # Константи, палітри, налаштування камер та погодних пресетів
├── shaders/
│   └── oceanShaders.js          # GLSL-шейдери поверхневих хвиль, морської піни та підводної товщі
├── utils/
│   ├── bottleMath.js            # Математика внутрішнього профілю пляшки (getBottleInnerRadius, isInsideBottle)
│   └── VoxelBuilder.js          # Конструктор геометрії з відсіканням прихованих граней (Hidden Face Culling)
├── core/
│   ├── EnvironmentManager.js    # Освітлення, PMREM-оточення, м'які PCF-тіні та 3D-блискавки з PointLight
│   └── InteractionManager.js    # Raycaster-взаємодія по оптимізованих проксі-мешах із тротлінгом
├── audio/
│   └── AudioSynthesizer.js      # Гібридний звуковий синтезатор на Web Audio API + Audio (гармати, хвилі, горн, монети)
├── world/
│   ├── BottleEnclosure.js       # Двостінна скляна колба (LatheGeometry + MeshPhysicalMaterial), корок та підставка
│   ├── VoxelOcean.js            # Воксельний океан, розрахунок плавучості (buoyancy) та керування хвилями
│   ├── VoxelShip.js             # Воксельний корабель, анімований Instanced-прапор, ліхтар каюти та гармати
│   ├── VoxelLandscape.js        # Розділені меші надводного архіпелагу (з тінями) та підводного рифу/дна
│   ├── VoxelWildlifeAndProps.js # Instanced-щупальця Кракена, плаваючі бочки, буй, хмари та денні чайки
│   └── ParticleManager.js       # Частинки THREE.Points (бризки, дощ, бульбашки, світлячки)
├── ui/
│   ├── HudController.js         # Контролер DOM-інтерфейсу (кнопки HUD, FPS-монітор, гарячі клавіші)
│   └── GuiController.js         # Налагоджувальна панель lil-gui (погода, параметри хвиль)
├── index.html
├── style.css
└── script.js                    # Головний точка входу та оркестратор анімаційного циклу tick()
```
